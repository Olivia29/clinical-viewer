1. 项目概述

1.1 项目背景与目标

本项目是影禾智能与四川大学华西医院（以下简称"华西医院"）战略合作的核心组成部分，共同开发一款面向临床医生的医学影像阅片器（以下简称"临床阅片器"）。产品以肺肿物患者的胸部 CT 随访数据为训练数据集，核心目标为实现 "图像与报告内容联动，不同随访时间节点病灶可对齐、可对比" 的智能化功能，提升临床医生在肿瘤随访、疗效评估等场景下的阅片效率与诊断精准度。

系统同时服务放射科日常阅片与临床科研（多期影像配准分析）两类场景，是连接诊断与决策支持的智能化工作台。

1.2 产品定位

临床阅片器定位为集成 AI 能力的交互式临床阅片工具：

  • 具备独立 UI，可作为独立系统使用；
  • 或通过 API 嵌入华西医院现有 PACS 系统（需对应软件供应商根据 API 提供定制化开发），作为临床医生日常阅片的核心工具。

    • 产品不仅提供传统阅片功能，更通过 AI 驱动的病灶时空对齐与图文联动，实现从"孤立信息浏览"到"综合信息辅助决策"的转变。

    1.3 核心价值主张

    对象价值
    对临床医生赋能通过自动化病灶对齐与可视化对比，将随访阅片时间从数分钟缩短至秒级；减少人为误差，提升诊断一致性
    对院级数据治理赋能沉淀结构化、标准化的高质量医疗数据资产，为临床科研、AI 模型训练及医院质量控制提供基础

    1.4 目标用户与使用场景

    用户角色场景核心诉求
    放射科诊断医师日常阅片、报告撰写高效浏览、精准标注、所见即所得报告
    临床科室医生（肿瘤/呼吸/胸外）肿瘤随访、疗效评估跨时点病灶对比、进展量化
    科研人员多期影像配准分析定量指标提取、数据沉淀

    2. 术语定义

    术语定义
    核心定义表影禾平台定义的解剖结构、病灶属性、征象描述的标准字段规范（含 AISU 肺肿物部分），用于多源结果的对齐、归并与结构化重构
    病灶家族将同一患者不同序列/不同检查中属于同一病灶的标注进行关联管理的一组对象，统一管理个体属性与对比信息
    图文联动结构化报告文本要素与影像分割/检测结果的双向关联：文字可定位影像，影像标注可回填报告
    配准（对齐）将同一患者不同时间点/不同序列影像中的解剖结构或病灶映射到统一空间坐标系的过程
    MPR多平面重建（冠状位/矢状位/任意斜位）
    结构化报告基于核心定义表组织的、字段化可提取的诊断报告（区别于自由文本）
    Report Plus在结构化报告基础上补充医生标注信息（测量、定性）形成的增强报告

    4.4 核心模块一：多时间节点影像解剖分割、病灶检测、智能对齐与对比

    本项目 AI 能力核心。对齐与对比的对象包括同一患者不同序列与不同检查时点（首诊/随访1/随访2…）。

    #### 4.4.1 多序列、多时点、多方位对齐场景（FR-ALIGN-01）

    场景说明示例
    同次检查内多序列对齐同一检查内不同序列间的病灶对齐胸部 CT 平扫 ↔ 增强序列病灶对齐
    不同检查时点对齐同一患者跨时点检查的图像/病灶对齐相隔数月的两次 CT 检查病灶对齐
    多扫描方位联动不同方位序列的识别对齐及联动横断位/冠状位/矢状位联动定位同一病灶

    #### 4.4.2 渐进式对齐模式（FR-ALIGN-02，复杂度递增）

    层级模式原理
    L1基于图像配准对齐平扫与增强按图像顺位对齐；不同方位按空间定位信息对齐
    L2基于解剖结构分割对齐基于肺（含肺叶、肺段）、骨、气管、心脏、大血管等位置固定解剖结构的分割结果，按整体空间位置配准
    L3解剖分割 + 病灶检测对齐在 L2 基础上按病灶检测结果，将临近对齐层面的病灶链接，判断核心病灶在同次/前后次检查中的存在与否及链接情况

    #### 4.4.3 算法自动对齐 + 医生手动微调（FR-ALIGN-03）

    编号需求项说明
    FR-ALIGN-04算法自动对齐基于核心定义表定义的关键解剖结构与病变，算法自动完成对齐
    FR-ALIGN-05医生手动微调提供手动编辑对齐结果：对 AI 自动对齐结果调整、确认或重新定义（解除/重置页面与病灶对齐关系）

    #### 4.4.4 量化对比与可视化（FR-ALIGN-06）

    编号需求项说明
    FR-ALIGN-07自动计算基于病灶对齐，自动计算病灶大小、体积、密度等关键临床参数的变化量及百分比
    FR-ALIGN-08可视化展示以表格、图表或叠加标注方式直观展示病灶随时间变化趋势（体积/密度曲线）
    FR-ALIGN-09目标家族管理支持将不同序列/检查中的同一病灶标注为"家族"，统一管理个体属性与对比信息

    4.5 核心模块二：图像与报告智能联动

    功能描述：报告结构化 + 文本要素提取，提取结果与图像分割/检测结果对齐联动。医生在报告中点击可交互要素（解剖结构、病灶）→ 直接定位到对应影像；在影像上标注/删除病灶 → 自动填充/删除报告对应字段。

    编号需求项优先级说明/验收
    FR-LINK-01报告驱动影像定位P0审核医生通过结构化报告中文字描述，一键跳转至提及的具体影像层面和病灶位置，无需手动翻阅
    FR-LINK-02影像标注驱动报告更新P0医生阅片中对病灶标注（测量、定性），系统自动补充至结构化报告对应模块，形成 Report Plus
    FR-LINK-03自动关联准确率 ★P0报告中文本描述与影像病灶区域自动关联准确率 ≥ 0.8
    FR-LINK-04关联关系持久化P0阅片完成后图文关联关系在系统内自动保存，下次打开可复现
    FR-LINK-05双向删除同步P1影像删除病灶标注 → 报告对应字段同步删除（或标记）

    4.6 配准对比模式（科研核心功能）

    编号需求项说明
    FR-REG-01触发条件阅片区至少显示 ≥2 个序列时，"配准对比"按钮才可点击
    FR-REG-02基准设定系统自动选择检查时间最近的序列作为基准序列（不可被替换）
    FR-REG-03布局适配进入配准模式后布局自动适配为 1x2 或 2x2（依窗口数量）
    FR-REG-04基准标识基准序列窗口以金色边框 + "⭐ 基准"标签标识
    FR-REG-05替换保护拖拽新序列至阅片区仅允许替换非基准序列；基准序列受保护
    FR-REG-06量化指标配准完成后自动计算病灶尺寸、密度、差值等量化指标，展示于各窗口左上角与右侧独立"配准对比"浮动面板（指标可按需更新）
    FR-REG-07退出配准点击"配准对比"按钮或重置视图退出，恢复普通浏览
    FR-REG-08手动配准无法自动配准的序列，支持手动标记病灶进行病灶关联（手动配准）

    4.7 窗口管理（拖拽新增与替换）

    编号需求项说明
    FR-WIN-01拖拽逻辑从左侧缩略图栏拖拽任意序列至中间阅片区
    FR-WIN-02容量规则窗口数 <4 → 新增该序列窗口，布局自动适应（1→2→4）；已达 4 窗（2x2）→ 新拖入序列替换当前最后一个窗口，始终保持最多 4 窗
    FR-WIN-03配准保护配准模式下拖拽仅允许替换非基准序列
    FR-WIN-04窗口关闭窗口支持单独关闭（非配准模式，保留 ≥1 窗）

    5. 核心流程

    5.1 数据载入与对齐流程（阅片前置）

    1. 在业务系统中选择患者的多序列及多次检查数据；

    2. 选择检查数据，推送进行分割、检测、报告生成及基于图像位置和解剖结构的初步对齐的综合算法推理；

    3. 进入对齐界面，医生查看对齐结果，可手动微调与确认对齐的图像位置；

    4. 查看对齐后的对比视图与量化报告。

    5.2 图文联动报告流程

    1. 医生在阅片器中浏览影像并进行病灶标注；

    2. 标注信息自动填充至结构化报告；

    3. 医生编辑报告文本，可点击文本跳转至对应影像；

    4. 阅片完成，图文关联关系在系统内自动保存。

    6. 核心定义表（AISU 肺肿物部分 · 示例）

    核心定义表是解剖结构、病灶、征象的结构化规范，是多源结果对齐与报告重构的依据。完整表含全部解剖结构与病变条目；此处列肺肿物核心部分作为字段/描述模板规范。

    6.1 肺肿物描述模板（结构化语句）

    中央型肺癌：

    「解剖结构」可见「属性A」「属性B」肿块影，密度「属性C」，边界「属性D」；局部「属性E」。

    属性必选取值（示例）描述词库
    A 位置/管壁必选主支气管/支气管管壁不规则增厚/官腔狭窄/官腔截断
    B 肿块密度必选软组织密度/混杂密度均匀/不均匀
    C 密度均匀性必选—均匀/不均匀
    D 边界必选—清晰/不清晰
    E 继发征象可选—肿块突入管腔/肿块包绕支气管/肿块包绕肺动脉/局部见低密度坏死区/临近肺组织牵拉改变，远端肺叶不张

    周围型肺癌 / 良性肿瘤：

    「解剖结构」可见「属性A」软组织密度肿块影，密度「属性B」，边界「属性C」，大小约「输入框」×「输入框」mm（良性肿瘤另含边缘「属性D」、直径「输入框」mm）。

    属性周围型肺癌良性肿瘤
    形态类圆形/不规则型类圆形/不规则型
    密度均匀/不均匀、高密度/混杂密度均匀/不均匀
    边界清晰/不清晰清晰/不清晰
    边缘—光滑/不光滑
    征象词库病灶呈分叶状/边缘可见长毛刺/边缘可见短毛刺/其内可见空泡征/其内可见空洞/其内可见磨玻璃成分/局部见低密度坏死区/临近胸膜凹陷/病灶侵犯临近骨组织呈溶骨性破坏同左（适用部分）

    6.2 核心定义表的作用

    1. 对齐依据：定义关键解剖结构与病变，作为自动对齐的语义锚点；

    2. 报告重构：全部报告数据经多模态模型文本拆解 + 核心定义表结构化重构；

    3. 图文联动基底：文本要素（解剖结构/病灶）→ 影像要素的双向映射字典。
